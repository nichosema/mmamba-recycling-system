# MMAMBA Recycling System

MMAMBA Mobile Recycling Services Uganda is a digital recycling collection and partner-management platform focused on plastic and scrap materials.

## Planned platform

- Customer mobile app
- Collector/driver mobile app
- Partner institution portal
- Admin dashboard
- Dynamic material pricing (UGX/kg)
- Waste earnings calculator
- Pickup requests and scheduling
- Google Maps and live collector tracking
- Verified collection weights and transaction records
- Partner registration for schools, bars, businesses and other institutions
- Recurring institutional collections
- Reports and analytics

## Planned stack

- Backend: Django + Django REST Framework
- Database: PostgreSQL
- Mobile: React Native
- Maps/location: Google Maps
- Authentication: JWT
- Notifications: Firebase

## Repository structure

The project will be organized into separate backend, mobile, admin-dashboard and documentation areas as implementation progresses.
