# MMAMBA System Architecture

## Core roles
- Customer
- Collector
- Partner
- Administrator

## Core domains
- Accounts and roles
- Materials and dynamic prices
- Earnings calculator
- Pickup requests
- Collector assignments
- Live location tracking
- Partner registration and recurring collections
- Verified weights and transactions
- Notifications
- Reports

## Material scope
MMAMBA handles plastic and scrap materials. E-waste and organic waste are excluded from the product scope.

## Pricing
Prices are stored per material per kilogram and controlled by administrators. Price changes should preserve price history.

## Estimated vs verified value
The public calculator provides an estimate using current buying prices. The final collection value is based on verified material type and weight recorded by an authorized collector.
